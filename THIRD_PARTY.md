# Drittanbieter-Material

## Notenschlüssel (Bravura)

Die Umrisse von Violin-, Bass- und Altschlüssel (SMuFL: `gClef`, `fClef`, `cClef`)
stammen aus der Musikschrift **Bravura** (© 2019 Steinberg Media Technologies GmbH,
Reserved Font Name „Bravura“), lizenziert unter der **SIL Open Font License 1.1**
(https://openfontlicense.org). Die Pfade sind als SVG-Daten in `src/ui/notensystem.mjs`
bzw. im gebündelten `src/app.js` eingebettet.
